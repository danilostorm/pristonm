## Bloqueios identificados

1. A assinatura original `META-INF/MOE_KEYS.*` não validava, porque o manifesto antigo inclui referências a pelo menos **23 pacotes `.pak` ausentes** (ex.: `assets/pack7.pak`, `assets/pack5.pak`). A assinatura do LAB apenas torna o ZIP Android verificável, **não repõe os dados do jogo**.
2. Nenhum arquivo `.pak` foi encontrado dentro dos clientes extraídos. Os recursos Urho3D estão majoritariamente soltos, possivelmente exigindo reconstrução de pacotes ou modificação do carregador.
3. O APK original tem API alvo 12. O Android 14 normalmente bloqueia instalação de alvos inferiores a 23, e Android 15 bloqueia inferiores a 24. Não elevar o alvo artificialmente sem revisar compatibilidade de APIs e permissões.
4. Não há teste de inicialização Android ou conexão ao StormPT concluído.
5. Os arquivos `.proto` do Mobile definem protocolo `NFMsg`. É necessário comparar mensagens, framing, login e estado com o servidor StormPT antes de criar o adaptador.
6. O cliente Web StormPT continua prévia sem autenticação e multiplayer prontos, conforme repositório `danilostorm/pristonweb`.
7. A unidade C: da VM do LAB StormPT reportou zero espaço livre em 10/11/2026; não instalar novos componentes nela até resolver.
